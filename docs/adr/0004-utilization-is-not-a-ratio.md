# ADR 0004：利用率不是一个可计算的比值，改记信号与工具的事实

- 状态：Accepted
- 日期：2026-08-23
- 修订：[ADR 0002](0002-utilization-as-first-class-goal.md) 决策 1 与 3 的度量部分；其余条款不变

## 背景

[ADR 0002](0002-utilization-as-first-class-goal.md) 把「资料利用率」立为与完整性并列的一等目标，
并在 [spec 11](../spec/11-utilization.md) §3.3 给了公式：

```
item.utilization = 已成功提取的信号数 / 探测为 present 的信号数
```

分母那一半是扎实的：ADR 0002 决策 3 要求「分母必须是探测到的事实，不得是估计」，
实现一期已经落地——stdlib 探测、三态、拿不准记 `unknown` 并排除出分母。

**但 ADR 0002 从未说过分子从哪来。** 一期实现走到接分子时，这个缺口暴露成一个循环：

> 分子要求知道「这份材料本来应该提取出多少信息」。那是 ground truth。
> 而如果 ADG 已经掌握 ground truth，就没有必要调用这些解析工具了。

这不是实现难度，是**原理上不可知**。同一场讨论里还暴露了第二个越界假设：
曾设想用「12 张图里 OCR 出了 3 张」表达部分提取，但探测器只数得到 `/Subtype /Image`
在字节流里出现几次——那既不等于「有几张有意义的图」，更无从知道 OCR 认出了几张。
文件级三态是探测能力的真实边界，任何比这更细的计数都是编的。

第三个事实来自代码：worker 的能力声明只到 **kind 级**，没有到信号级。

```json
pypdf     handles: [{"kind": "pdf",   "role": "parse"}]
rapidocr  handles: [{"kind": "image", "role": "parse"}]
```

因此连「哪个信号没有工具覆盖」也不能直接算出来——rapidocr 对一份 PDF 根本不在候选里，
PDF 里的图要先经 `pdf_render` 转成 image 才轮得到它。

## 决策

1. **撤销「利用率」作为比值度量。** 不再计算、不再输出 `item.utilization` 或包级利用率百分比。
   一个分子不可知的比值，无论怎么实现都是在编数字，与项目「不假装成功」的承诺直接冲突。

2. **改为输出两组并列的事实**，不做除法，也不合成任何单一评分：
   - **探测到什么**：信号三态（present / absent / unknown）——不需要 ground truth，从字节里读得出来。
   - **跑过什么**：实际调用了哪些工具、产出了哪些 rendition——记录在案的执行事实。

   「够不够、要不要再跑一个」由调用方判断。ADG 提供事实，不提供分数。

3. **探测能力原样保留。** 它不依赖分子，且有两处独立价值：
   它是给调用方的事实陈述，也是增益轨的触发条件（探测到没有图就不必启动 OCR，
   这是 ADR 0002 决策 6「探测门控」最大的一笔成本节省）。

4. **ADG 不评判结果质量。** ADR 0002 决策 5 原本只说「多轨读数分歧只记录、不裁决」，
   本条把它推广到全部输出：多个工具产出多个 rendition，哪个好、为什么好，
   ADG 不告诉调用方，也不需要告诉——判断权在调用方，和「摄取 ≠ 取证」同源。

5. **不为补上分子而扩展 worker 能力声明。** 把 `handles` 从 kind 级细化到信号级，
   只能换来「工具自称能处理该信号」，仍然不是「实际提取到了多少」。
   它把一个不可知的量替换成一个可疑的量，不解决问题，故不做。

## 后果

- ADR 0002 决策 1 中「利用率作为度量」的部分作废；该 ADR 的其余条款——增益轨（决策 2）、
  多轨产物不合并（决策 4）、分歧只记录不裁决（决策 5）、成本控制五机制（决策 6）——全部不变。
  **多视角提取这个方向没有被推翻，被推翻的只是给它打分的那把尺子。**
- spec 11 §3.3 的公式删除，§一/§三改写为事实陈述口径；§七验证矩阵中依赖比值的判据相应调整。
- `gateway/signals.py` 的 `utilization()` 与 `gaps()` 删除——两者都以「已提取的信号集合」
  为入参，而那个集合不可知。`probe` / `normalize` / `denominator` / `unknown_signals` 保留。
- 报告与 `adg status` 不会出现利用率百分比。完整性仍用 `extraction_coverage` 表达，
  且已带消歧说明（[ADR 0003](0003-distribution-and-target-runtime.md) 决策 7），
  不再有「两个百分比并列、读者分不清」的风险——因为只剩一个。
- 本 ADR 记录的是一次**方向修正而非失败**：ADR 0002 对问题的判断（完整性 100% 不等于
  信息拿全了）依然成立，错的是以为这件事可以被量化成一个数。
